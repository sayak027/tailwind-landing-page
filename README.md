# Tailwind Landing Page

A responsive landing page built using HTML and Tailwind CSS as a learning and practice project.

## 🚀 Tech Stack

- HTML5
- Tailwind CSS
- Responsive Design

## 📌 About

This project was created to practice Tailwind CSS concepts such as:

- Flexbox
- Responsive breakpoints
- Spacing
- Typography
- Colors
- Borders
- Hover states
- Responsive navigation

## 📱 Responsive Design

The website is designed for:

- Desktop
- Tablet
- Mobile

## 🎯 Purpose

This is a learning/practice project created while learning Tailwind CSS.

It is inspired by the PW Skills website and is not an official PW Skills website.
